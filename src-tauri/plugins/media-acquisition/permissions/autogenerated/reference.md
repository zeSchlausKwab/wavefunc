## Default Permission

Allow WaveFunc to acquire media locally and upload it to Blossom

#### This default permission set includes the following:

- `allow-prepare`
- `allow-status`
- `allow-upload`
- `allow-discard`
- `allow-cancel`
- `allow-register-listener`
- `allow-remove-listener`
