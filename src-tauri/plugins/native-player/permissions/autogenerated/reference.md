## Default Permission

Allow WaveFunc to control its native Android radio player

#### This default permission set includes the following:

- `allow-play`
- `allow-pause`
- `allow-resume`
- `allow-stop`
- `allow-update-metadata`
- `allow-set-volume`
- `allow-register-listener`
- `allow-remove-listener`
